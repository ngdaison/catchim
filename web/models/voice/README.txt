THƯ MỤC CHỨA MODEL GIỌNG CLONE GPT-SoVITS
========================================

Để kích hoạt giọng đọc clone của bạn trên Web Catchim, hãy đặt 3 file sau vào thư mục này:

1. model.pth    : File trọng số âm sắc SoVITS (từ thư mục SoVITS_weights của GPT-SoVITS)
2. model.ckpt   : File trọng số ngữ điệu GPT (từ thư mục GPT_weights của GPT-SoVITS)
3. sample.wav   : Đoạn ghi âm mẫu ngắn 3 - 5 giây của giọng đọc này

Bạn có thể chỉnh sửa tên giọng và câu mẫu hiển thị trong file info.json cùng thư mục.
